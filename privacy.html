Valerie V2 Privacy Policy

Valerie V2 is a personal assistant used only by its developer, on the developer's own computer, with the developer's own Gmail account. No other person's data is accessed.

What the app accesses

With the developer's permission, the app uses the Gmail API to search and read the developer's messages, change labels and read state, archive, move messages to Trash, and create drafts. It does not send email.

How the data is used

Gmail data is used only to carry out the developer's own requests inside the app. It is not used for advertising, is not sold, and is not shared with other people. No person reads it.

Where the data goes

Gmail content that the assistant retrieves is processed on the developer's computer and may appear in a local conversation log stored there. When the developer asks a conversational question, parts of the conversation, which can include retrieved email content, may be sent to the Anthropic API to produce a reply. Authorization tokens are stored only in the developer's computer environment and are never published.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The developer can revoke the app's access at any time from the Google Account permissions page.
