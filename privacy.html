Valerie V2 Privacy Policy

Last updated: November 10, 2026

Valerie V2 is a personal assistant used only by its developer, on the developer's own computer, with the developer's own Gmail account. No other person's data is accessed.

What the app accesses

With the developer's permission, the app uses the Gmail API to search and read the developer's messages, change labels and read state, archive, move messages to Trash, create drafts, and download image attachments so they can be forwarded to the developer. It does not send email.

How the data is used

Gmail data is used only to carry out the developer's own requests inside the app. It is not used for advertising, is not sold, and is not shared with other people. No person reads it.

Where the data goes

The assistant runs on the developer's computer, using an AI model that also runs on that computer. Gmail content that the assistant retrieves is processed there and is not sent to any cloud AI service. It may appear in conversation history, and in short summaries of that history, stored only on the developer's computer and in the developer's own backups.

The assistant talks to the developer through a private Telegram chat with the developer's own bot. Its replies, which can include summaries of email, travel through Telegram's servers, and bot chats are not end-to-end encrypted. When the developer asks for an image attachment, it is downloaded to the computer briefly, forwarded to that chat, and then deleted from the computer.

If the developer asks the assistant to search the web, the text of that search request is sent to a web search service. Authorization tokens are stored only in the developer's computer environment and are never published.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The developer can revoke the app's access at any time from the Google Account permissions page.
